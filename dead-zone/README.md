# PROJECT DEAD ZONE

PC 웹브라우저용 3D 쿼터뷰 좀비 서바이벌 슈팅 게임입니다.

- **1단계:** 이동 · 마우스 조준 · 자동소총 사격 · 쿼터뷰 카메라 · 폐허 도시 테스트 맵
- **2단계:** 좀비 AI(상태 기반 + 흐름장 경로 탐색) · 좀비 생성 · 총기 피해 · 플레이어 체력 · 사망과 재시작. 1단계의 연습 표적은 좀비로 대체했습니다.
- **3단계:** 생존 시간 · 60초 웨이브 · 웨이브별 난이도 · 웨이브 알림 · 게임 오버 결과와 개인 최고 기록(localStorage)
- **4단계:** 경험치 결정 · 레벨업 · 무작위 강화 카드(12종, 희귀도) · 능력치 재계산
- **5단계:** 총기 5종 · 근접 무기 4종 · 무기 슬롯(총 2 + 근접 1) · 교체 · 무기 보상 · 숙련도 · 근접 강화 5종 (4단계 시점은 git 태그 `dead-zone-stage4-backup`)
- **6단계:** 특수 좀비 4종(러너 · 탱커 · 스피터 · 폭발) · 엘리트 변형 · 보스 THE ABOMINATION(패턴 3종 · 2페이즈) · 웨이브별 등장 규칙 · 위험 범위 표시 · 보스 체력바 · 보스 처치 보상

TypeScript + Three.js(r170) + Vite 5 로 만들었고, 외부 모델 · 텍스처 · 음원은 사용하지 않았습니다.
모든 형태와 질감은 절차적으로 생성하고, 효과음은 Web Audio 로 합성합니다.

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 배포용 빌드 (타입 검사 포함)
npm run preview    # 빌드 결과 확인
```

WebGL2 를 지원하는 최신 Chrome · Edge 가 필요합니다. Firefox 는 테스트하지 않았습니다.

## 그래픽 품질

시작 화면 · 일시정지 화면에서 고를 수 있고, 고른 값은 브라우저에 저장됩니다. 기본값은 '중간' 입니다.

| 품질 | 그림자 | 가로등 점광원 | 렌더 배율 상한 |
|---|---|---|---|
| 높음 | 2048 | 3 | 1.5 |
| 중간 | 1024 | 1 | 1.0 |
| 낮음 | 끔 | 0 | 0.85 |

F3 패널에서 볼 수 있는 값:
- **CPU 시간:** 게임이 프레임마다 쓰는 시간. 이 값이 작은데 FPS 가 낮으면 병목은 GPU 이거나 프레임 상한입니다.
- **GPU:** 브라우저가 실제로 쓰는 그래픽 장치 이름. "SwiftShader" · "Basic Render" 가 보이면 하드웨어 가속이 꺼져 있는 것입니다.

동적 해상도는 해상도를 낮춰도 FPS 가 8% 이상 오르지 않으면 원래대로 되돌리고 30초간 더 낮추지 않습니다. 절전 모드의 30FPS 상한처럼 해상도와 무관한 경우에 화질만 떨어지는 것을 막기 위해서입니다.

## 6단계: 특수 좀비 · 엘리트 · 보스

### 구조

적 종류마다 AI 를 따로 만들지 않고, 기존 `Zombie`(생성 · 추적 · 경로 · 피격 · 넉백 · 사망)를 공통으로 쓰면서 종류별 **행동 모듈**만 덧붙입니다.

| 파일 | 역할 |
|---|---|
| `enemies/EnemyData.ts` | 종류별 능력치 · 엘리트 배율 · 웨이브별 등장 표(가중치 · 동시 상한) · 보스 성장 · 보스 보상 |
| `enemies/EnemyBehaviors.ts` | 행동 모듈 (러너 가속 · 스피터 거리 유지/사격 · 폭발 준비 · 보스 패턴 3종 + 2페이즈) · 위험 범위 계산 |
| `enemies/Zombie.ts` | 공통 적 클래스. `Special` 상태 · 상태 이상 저항 · 곡선 이동(steerRate) · 위험 범위 판정(`zoneContains`) 추가 |
| `enemies/ZombieManager.ts` | 기존 생성 루프 하나에서 종류 · 엘리트 선택, 동시 상한, 보스 생성 위치, 보스 생존 중 일반 좀비 조정 |
| `enemies/BossDirector.ts` | 5웨이브마다 보스 1회, 중복 방지, 이전 보스 생존 시 대기 |
| `enemies/EnemyProjectiles.ts` | 스피터 독성 투사체 (객체 풀, 벽 충돌, 동시 비행 · 발사 간격 제한) |
| `enemies/EnemyTelegraphs.ts` | 바닥 위험 범위 표시 (원 · 부채꼴 · 직선). 피해 판정과 같은 값을 사용 |
| `enemies/ZombieRenderer.ts` | 같은 인스턴스 메시로 종류별 체형 · 걸음걸이 · 공격 동작, 엘리트 금색 · 빛 고리 · 체력바, 화면 밖 생략 |

위험 범위 기준은 모두 **"플레이어 중심이 표시된 범위 안이면 피해"** 입니다. 바닥 외곽선이 전체 범위, 안쪽 채움이 자라서 외곽선에 닿는 순간이 판정입니다.

### 적 종류 (기본값, 웨이브 체력 · 속도 배율은 보스를 제외하고 적용)

| 종류 | 체력 | 속도 | 공격 | 간격 | 경험치 | 넉백 저항 | 특징 |
|---|---|---|---|---|---|---|---|
| 워커 (기존) | 100 | 2.2 | 10 | 1.2초 | 10 | 0 | 변경 없음 |
| 러너 | 60 | 4.5 | 8 | 0.8초 | 15 | 0.05 | 2.6~8m 에서 0.3초 웅크린 뒤 0.65초 가속(×1.5). 가속 중 회전 1.8rad/s 로 제한 → 옆으로 피하면 지나침 |
| 탱커 | 500 | 1.4 | 25 | 1.8초 | 40 | 0.8 | 큰 체형. 0.95초 예비 동작 동안 바닥에 부채꼴 범위 표시. 일반 피격에 움찔하지 않음 |
| 스피터 | 90 | 1.8 | 12 (원거리) | 2.5초 | 25 | 0.1 | 7~10.5m 유지, 5m 안이면 후퇴, 0.65초 준비 후 독 투사체(속도 11, 사거리 12). 발사 후 옆으로 재배치 |
| 폭발 좀비 | 120 | 2.4 | 30 (폭발) | - | 25 | 0.15 | 2.2m 안에서 준비 시작 → 1.2초 경고(반경 4 원 · 발광 · 경고음) → 폭발 후 제거 |
| 보스 | 3000 | 1.8 | 35 | - | 300 | 1 (면역) | 아래 참고 |

- 폭발 좀비를 먼저 처치하면 폭발하지 않고 일반 사망(처치 수 · 경험치 지급). 자폭은 처치가 아니므로 경험치가 없습니다.
- 폭발은 플레이어에게만 피해를 주므로 다른 좀비(폭발 좀비 포함)가 연쇄 폭발하지 않습니다.
- 독 투사체: 동시 비행 최대 4발, 서로 다른 스피터의 발사 간격 최소 0.4초. 준비 동작을 시작할 때 자리를 예약하므로 여러 마리가 한꺼번에 쏘지 못합니다.
- 상태 이상 저항: 경직 시간 × (1 - 저항). 0.05초보다 짧으면 경직 없음 (탱커 · 보스).

### 엘리트

기존 종류의 변형입니다(행동은 원래 종류 그대로). 체력 ×3 · 피해 ×1.5 · 속도 ×1.1 · 경험치 ×5 · 넉백 저항은 남은 값의 50% 추가(워커 0 → 0.5, 탱커 0.8 → 0.9) · 크기 ×1.18.
금색 옷 · 금색 눈 · 발밑 빛 고리 · 머리 위 금색 체력바(항상 표시). 등장 시 "⚠ 엘리트 ○○ 출현!" 알림.
웨이브 7 부터 생성 1회마다 5% (+0.5%/웨이브, 최대 12%), 동시 최대 2마리(웨이브 12 부터 3마리).

### 보스: THE ABOMINATION

| 패턴 | 조건 | 예고 | 판정 | 회복 |
|---|---|---|---|---|
| A 근접 강타 | 3m 안 | 팔을 들어 올림 + 부채꼴 3.3m · 100° (0.8초) | 피해 35 | 0.7초 |
| B 돌진 | 5.5~22m, 시야 확보 | 몸을 낮추고 앞발을 긁음 + 직선 표시 (1.2초, 마지막 0.4초는 방향 고정) | 몸에 닿으면 피해 42 (1회) | 0.9초, 벽 충돌 시 1.6초 |
| C 지면 강타 | 4.2m 안 (2페이즈 5.5m) | 양팔을 머리 위로 + 원 반경 5 (1.35초) | 피해 31.5 | 1.0초 |

- 돌진: 속도 12, 최대 18m(앞 장애물까지). 돌진 중 회전 0.12rad/s 로 제한. 장애물에 부딪히거나 거리를 다 가면 종료. 직선 표시 길이 = 이동 거리 + 몸이 닿는 거리.
- 패턴 사이 최소 0.6초 간격, 돌진 쿨다운 8초, 지면 강타 7초.
- **2페이즈 (체력 50% 이하, 한 번만):** 1.4초 포효 연출(붉은 충격파 · 알림 · 화면 흔들림) → 쿨다운 · 회복 ×0.7, 예비 동작 ×0.85, 속도 ×1.15, 돌진 쿨다운 5초, 지면 강타 반경 ×1.3. 눈 · 등 균열이 붉게 바뀌고 체력바가 맥동합니다.
- 넉백 · 경직 면역. 샷건은 산탄 8발이 각각 한 번씩 판정되고(같은 산탄이 두 번 맞지 않음), 관통 탄도 같은 보스에게는 한 번만 피해를 줍니다.

**등장:** 5 · 10 · 15 · 20 … 웨이브 시작 2.8초 뒤(웨이브 알림과 겹치지 않게), 플레이어에서 13~20m 떨어지고 주변 2.6m 가 비어 있는 곳에서 땅을 뚫고 올라옵니다(2.4초). 웨이브마다 한 번만 처리하고, 동시에 1마리만 존재합니다. 보스 웨이브에 이전 보스가 살아 있으면 대기했다가 이전 보스 처치 4초 뒤 등장합니다. n번째 보스: 체력 × (1 + 0.6(n-1)), 피해 × (1 + 0.15(n-1)) (10웨이브 = 체력 4800 · 피해 40.25). 보스가 살아 있는 동안 일반 좀비 상한 ×0.6, 생성 간격 ×1.4.

**처치 보상:** 경험치 300(경험치 결정 10개로 떨어져 일반 경험치 시스템으로 흡수), 체력 30 회복(최대 체력까지), "BOSS DEFEATED" 알림. `Game.onBossDefeated(reward)` 와 `BOSS_REWARD.items` 는 향후 희귀 무기 · 특별 강화 보상 자리입니다.

  - 휘두르는 동안에는 사격 · 교체가 막히고, 이동은 됩니다.
  - 재장전 중에 근접 공격을 하면 재장전이 취소되고 탄약은 그대로입니다. 탄약이 0 이어도 근접 공격은 됩니다.

### 무기 획득

- **보상 시점:** 레벨 2 · 5 · 8 에 근접 무기 보상, 레벨 3 · 6 · 9 에 총기 보상이 나옵니다.
- **총기 보상:** 장착 중이 아닌 SMG · 샷건 · LMG 가 후보입니다. 현재 두 총과 능력치를 비교해 보고 교체할 슬롯을 고르거나 거절합니다.
- **근접 보상:** 장착 중이 아닌 마체테 · 방망이 · 도끼가 후보입니다. 바꾸거나 거절합니다.
- **해금과 장착:** 해금(`unlocked`)과 장착(`slots`)은 따로 관리합니다. 한 번 바꾼 무기도 나중에 다시 후보로 나옵니다.
- **보상 대기열:** 강화 · 총기 · 근접 보상을 하나의 대기열로 처리합니다. 같은 레벨 안에서는 강화 → 총기 → 근접 순서이고, 다 끝나야 게임이 재개됩니다.

### 숙련도 · 능력치 계산

- **숙련도:**
  - 무기마다 따로, 실제로 깎은 체력(남은 체력까지만)으로 쌓입니다.
  - 총기 600 / 1800 / 4000 / 8000, 근접 250 / 750 / 1700 / 3400 에서 Lv2~5 가 되고, 피해가 +5 / 10 / 15 / 20% 늘어납니다.
  - 무기를 바꿔도 이번 판 동안 유지되고, 다시 시작하면 초기화됩니다.
- **최종 능력치:** 강화 레벨에서 보정값을 계산한 뒤(`computeStats`), 무기마다 다시 계산합니다.
  - `총기 피해 = 기본값 × (1 + 총기 강화 + 숙련도)`
  - `근접 피해 = 기본값 × (1 + 근접 강화 + 숙련도)`
  - 총기 강화(공격력 · 연사 · 탄창 · 재장전 · 관통)는 모든 총기에만, 근접 강화는 근접 무기에만 적용됩니다. 치명타만 둘 다에 적용됩니다.
  - 항상 기본값에서 다시 계산하므로 교체 · 재획득 · 반복 강화로 값이 겹쳐 곱해지지 않습니다.
- **근접 강화 5종:**
  - 근접 공격력 +15% (최대 5)
  - 광역 타격 사거리 +10% (최대 5)
  - 신속 타격 간격 -10% (최대 5)
  - 충격 강화 넉백 +20% (최대 5)
  - 흡혈 타격: 근접으로 처치하면 레벨당 5 회복 (최대 3, 최대 체력 초과 없음)
- **상 · 하한:** 연사 ×1.8, 재장전 ×0.35, 근접 간격 ×0.5, 근접 사거리 ×1.5, 넉백 ×2, 피해 감소 60%

### 경험치 · 레벨

- **결정:** 좀비 1마리당 10 XP(`ZOMBIE_TYPES.walker.xp`), 밝은 청록색입니다.
  - 기본 획득 범위는 2.5 입니다. 범위에 들어오면 가속하며 최고 12 단위/초로 끌려옵니다.
  - 결정은 화면 밖에 있어도 사라지지 않습니다.
- **요구량** (`xpToNextLevel()`): 30, 45, 65, 90, 120, 이후 `120 + 40k + 4k²` (164, 216, 276, 344, 420 …)
- **결정 최적화:**
  - 평소에는 처치마다 항상 새 결정이 떨어지고, 기존 결정과 겹치지 않도록 살짝 떨어진 자리에 놓입니다.
  - 결정이 120개 이상 쌓였을 때만 1.2 안의 결정을 하나로 합치고, 160개를 넘으면 가장 가까운 결정에 합칩니다(총 경험치 손실 없음).
  - 결정은 드로우콜 2회(결정 + 바닥 빛)로 그립니다.
- **레벨업 화면:**
  - 이동 · 사격 · 좀비 · 생성 · 투사체 · 생존 시간 · 웨이브 · 결정이 모두 멈추고, 렌더와 UI 입력만 유지됩니다.
  - ESC 로 닫을 수 없습니다. 게임 오버가 항상 우선합니다.
  - 화면이 뜬 직후 0.45초 동안은 입력을 받지 않습니다(사격 중 연타로 카드가 잘못 골라지는 것 방지). 고른 뒤에는 입력을 잠가 중복 적용을 막습니다.

### 능력치 계산 (`computeStats`)

- **계산 방식:** `현재값 = 기본값 × (1 + 레벨 × 수치)` 를 항상 기본값에서 다시 계산합니다. 강화를 거듭해도 배율이 곱해져 폭증하지 않습니다(예: 공격력 25 → 28.75 → 32.5).
- **상 · 하한:**
  - 발사 속도 최대 ×1.8, 재장전 시간 최소 ×0.35, 이동 속도 최대 ×1.6
  - 피해 감소 최대 60%, 치명타 최대 50%, 획득 범위 최대 ×3
- **탄창이 커질 때:** 늘어난 만큼 탄을 바로 채워 줍니다.
- **재시작:** 강화 레벨을 비우고 다시 계산하므로 모든 능력치가 기본값으로 돌아갑니다(영구 성장 없음).

## 3단계: 웨이브와 생존

- **생존 시간 · 웨이브** (`waves/WaveSystem.ts`)

  | 4 | 1.1초 | 30 | 1.45 | 1.06 |
  | 5 | 0.9초 | 35 | 1.60 | 1.10 |

- **좀비 AI** (`enemies/Zombie.ts`)
  - 상태: Spawn → Chase ⇄ Attack, Chase → Hit → Chase, 모든 상태 → Dead.
  - 상태가 떨리지 않도록 세 가지를 둡니다.
    - 공격 시작은 사거리의 90% 안에서만 합니다.
    - 정지 거리에 히스테리시스를 둡니다(가까이 붙으면 멈추고, 더 멀어져야 다시 움직임).
    - 피격 경직 반응 사이에 최소 간격을 둡니다.
  - 공격 중에 맞으면 공격이 끊기지 않습니다(피해와 섬광만 적용).
- **경로 탐색** (`world/NavGrid.ts`)
  - 1단위 격자에서 장애물 + 여유 반경 0.5 가 닿는 칸을 막습니다.
  - 플레이어 칸에서 출발하는 다익스트라 흐름장을 한 번 계산하면 모든 좀비가 같이 씁니다. 플레이어가 다른 칸으로 옮겼을 때만, 최대 0.25초에 한 번 다시 계산합니다.
  - 좀비는 몸 폭으로 직선 시야를 0.2초마다 검사합니다. 시야가 열려 있으면 직진하고, 아니면 흐름장을 따라 우회합니다.
  - 0.7초 이상 막히면 옆으로 비켜 갑니다.
- **겹침 방지** (`ZombieManager.separate`)
  - 좀비끼리 위치를 서로 밀어냅니다. 공격 중인 좀비는 덜 밀립니다.
  - 플레이어와 겹친 좀비는 밖으로 밀어냅니다. 플레이어는 밀리지 않으므로 조작감이 그대로입니다.
  - 밀어낸 뒤 다시 벽 충돌을 처리합니다.
- **렌더링** (`enemies/ZombieRenderer.ts`)
  - 부위 11개를 InstancedMesh 로 그려, 좀비 수와 관계없이 드로우콜이 약 12회입니다.
  - 지오메트리 · 재질은 모두 공유합니다. 옷 · 피부색과 피격 섬광은 인스턴스 색상으로 표현합니다.
  - 숨겨진 뼈대 하나에 좀비마다 자세를 적용해 부위 행렬을 읽어 옵니다.
  - 좀비 객체는 풀에서 재사용합니다.
- **사망 · 재시작**
  - 플레이어가 죽으면 이동 · 사격 · AI · 생성이 즉시 멈추고, 쓰러지는 동작 1.3초 뒤 GAME OVER 화면이 뜹니다.
  - "다시 시작"을 누르면 새로고침 없이 위치 · 체력 · 탄약 · 좀비 · 처치 수 · 생성 타이머 · 투사체 · 이펙트를 초기화합니다.

```
  camera/GameCamera.ts       고정 방향 쿼터뷰, 추적, 건물 가림 반투명
  weapons/
    Weapon.ts                발사 간격 · 탄약 · 재장전 상태 머신 (이벤트 발행)
    Projectile.ts            투사체 풀, 선분 충돌, 궤적 표시
  combat/Damageable.ts       피해 대상 인터페이스 + 판정 레지스트리
  enemies/
    Zombie.ts                좀비 1마리: 상태 기반 AI, 공격 판정, Damageable 구현
    ZombieManager.ts         생성 · 갱신 · 겹침 방지 · 시체 정리 · 객체 풀
    ZombieRenderer.ts        부위별 InstancedMesh + 절차적 애니메이션 + 체력 바
  world/NavGrid.ts           격자 경로 탐색 (흐름장)
  effects/                   총구 화염 · 탄피 · 불꽃 · 연기 · 파편 (InstancedMesh 풀)
  ui/                        HUD · 조준 커서 · 디버그 패널
```

시스템 간 의존 관계는 다음과 같습니다.

- `Weapon` 은 `WeaponSocket`(총구 위치 · 방향) 만 알고, 발사하면 `onFire` 이벤트만 냅니다.
  투사체 · 이펙트 · 사운드 · 애니메이션은 `Game` 에서 이 이벤트를 각각 구독합니다.
- 투사체는 `Damageable` 인터페이스만 압니다. 다음 단계의 좀비도 같은 인터페이스를 구현해 `DamageableRegistry` 에 등록하면 같은 피해 시스템을 그대로 씁니다.
- `Player` 는 입력 장치를 모르고 `PlayerCommand`(이동 벡터 + 조준점) 만 받습니다.
- 애니메이션(`PlayerModel`)은 게임 상태를 읽기만 하는 시각 계층입니다. 이동 · 사격 판정에 영향을 주지 않습니다.
- 게임 로직은 1/120초 고정 간격으로 돌고, 화면은 두 스텝 사이를 보간해 그립니다.

## 구현 내용

- **맵 (100×100)**
  - 교차로와 4방향 도로, 차선(황색 중앙선, 점선, 가장자리선, 횡단보도, 정지선)
  - 파손된 건물 7동(무너진 윤곽, 철근, 깨진 창, 잔해)과 무너진 건물 터 2곳
  - 가로등 16개(켜짐 · 꺼짐 · 기울어짐, 점광원 6개)
  - 버려진 승용차 13대, 화물 트럭 1대
  - 방호벽, 모래주머니, 드럼통, 상자, 팔레트, 타이어, 꼬깔, 쓰레기봉투
  - 바닥 얼룩, 외곽 장벽과 철조망, 맵 밖 건물 실루엣, 안개
  - 해 질 녘 조명과 그림자. 그림자 카메라는 플레이어를 따라다닙니다.
- **충돌**
  - 모든 바닥은 y=0 이고 캐릭터 발바닥도 정확히 y=0 입니다.
  - 건물 · 차량(회전 상자) · 장애물과 원 vs 상자로 밀어내며 충돌하고, 벽을 따라 미끄러집니다.
  - 맵 경계 밖으로 나갈 수 없습니다.
  - 표적과 시작 지점 주변에는 소품을 두지 않습니다.
  - 격자 샘플 기준으로 맵의 약 80% 를 이동할 수 있습니다.
- **캐릭터**
  - 모자 · 고글을 쓴 머리, 조끼 · 배낭을 멘 몸통, IK 로 총을 잡는 팔, 무릎 관절이 있는 다리, 손에 든 소총을 절차적으로 모델링했습니다.
  - 발밑의 원과 화살표로 바라보는 방향을 표시합니다.
- **이동**
  - 카메라 기준 WASD 입니다. 대각선도 같은 속도(6.2 u/s)로 정규화합니다.
  - 약 0.1초에 최고속에 도달하고, 손을 떼면 약 0.08초 만에 정지합니다. 정지 후에는 미끄러지지 않습니다.
- **조준**
  - 카메라 레이를 총구 높이 평면과 교차시켜 조준점을 구합니다.
  - 오른쪽 어깨에 견착한 총구선이 조준점을 정확히 지나도록 몸을 회전합니다(총구 좌우 오프셋 보정).
  - 이동 방향과 조준 방향은 독립입니다.
  - 지면 대신 총구 높이 평면을 쓴 이유: 수평으로 날아가는 총알이 화면상 커서 바로 위를 지나가게 하기 위해서입니다. 지면을 쓰면 원근 때문에 총알이 커서 위쪽으로 빗나가 보입니다.
- **자동소총 (M-17)**
  - 30발, 초당 8발, 재장전 1.8초, 탄속 60, 사거리 45, 1발 25 피해, 탄 퍼짐 ±0.8°.
  - 저프레임에서도 탄 간격을 유지합니다(누적 쿨다운).
  - 마지막 탄을 쏘는 즉시 스스로 재장전합니다. 그동안 발사가 멈추고, 끝난 뒤 방아쇠를 계속 누르고 있으면 다시 연사합니다. (`autoReloadOnEmpty: false` 면 R 키로만)
- **투사체**
  - 64개 풀을 씁니다. 매 스텝 이동 구간을 선분으로 검사해 빠른 탄도 관통하지 않습니다.
  - 사거리에 도달하거나 무언가에 맞으면 풀로 돌아갑니다.
  - 총알 높이(1.32)보다 낮은 장애물(방호벽 · 드럼통 · 모래주머니)은 넘어가고, 높은 것(건물 · 차량 · 상자 더미 · 가로등)은 막힙니다.
- **연습 표적:** 1단계에서 8개를 두었고, 2단계에서 좀비로 대체했습니다.
- **카메라**
  - 원근, 50° 내려다보기, 방위 45° 고정, 거리 17.5 입니다.
  - 부드럽게 추적합니다. 조준 방향 미리 보기(`aimLookAhead`)는 기본으로 꺼 두었습니다.
  - 캐릭터를 가리는 건물은 반투명으로 처리합니다.
- **애니메이션** (모두 절차적)
  - 대기(호흡, 짝다리), 걷기(하체가 이동 방향으로 비틀리고 뒷걸음질 지원, 낮은 발이 항상 지면에 닿도록 높이 보정)
  - 조준 자세 ↔ 총구를 내린 대기 자세 전환
  - 사격 반동
  - 재장전: 총을 기울이고, 빈 탄창이 떨어지고, 허리 파우치에서 새 탄창을 꺼내 끼웁니다.
- **이펙트**
  - 총구 화염, 섬광 조명, 총구 연기, 탄피 배출(바닥에서 튐), 궤적, 벽 피격 불꽃 · 먼지 · 파편, 표적 파편, 파괴 효과
  - 파티클은 4개의 InstancedMesh 풀로 그리며, 각각 드로우콜 1회입니다.
- **UI**
  - 왼쪽 위: 제목, 체력 100/100
  - 오른쪽 아래: 무기 이름, 탄약 수 · 탄 표시, 탄약 부족 · 재장전 안내
  - 왼쪽 아래: 조작 안내
  - 조준 커서: 가운데 십자선은 운영체제 마우스 커서로 그려 게임 프레임과 상관없이 마우스와 즉시 함께 움직입니다. 탄 퍼짐 · 재장전 원 · 명중 표시는 마우스 이벤트에서 바로 위치를 옮깁니다.
- **안정성**
  - 창 포커스를 잃거나 탭이 숨겨지면 일시정지하고 입력을 초기화합니다.
  - ESC 로 일시정지합니다.
  - 창 크기 변경에 대응합니다.
  - WebGL2 미지원 · 컨텍스트 손실 시 안내 화면을 띄웁니다.
  - `dispose()` 로 리소스를 해제합니다.

## 알려진 문제 · 검증하지 못한 것

- **6단계 이전 테스트 결과:** `verify5` · `verify4` 는 모두 통과. `verify3` 의 2개 항목은 6단계 규칙 때문에 기대값이 달라졌습니다. 5웨이브 생성 간격이 1.10 → 1.26초로 늘어난 것은 보스가 살아 있는 동안 일반 좀비 생성을 ×1.4 로 늦추는 규칙 때문입니다. "화면 안 생성"이 1건 나오는 경우가 있는데, 일반 좀비는 계속 화면 밖에서만 생성되고 보스만 등장 연출이 보이도록 화면 안에 나올 수 있습니다(13m 이상 떨어진 곳에서 2.4초간 올라옴). `verify2` 의 생성 간격 항목 1개는 6단계 이전부터 실패하던 항목입니다(2단계의 고정 간격 생성 기준).
- **6단계 밸런스 · 체감:** 특수 좀비 · 보스 수치와 등장 비율은 테스트 봇으로만 확인했습니다. 사람이 직접 보스를 상대하는 난이도, 독 투사체 · 돌진의 피하기 쉬운 정도는 확인하지 못했습니다. 플레이어가 보스보다 훨씬 빨라 달아나기만 하면 보스는 돌진만 씁니다.
- **보스와 좁은 길:** 보스는 몸이 커서(반경 1.25) 좁은 골목에서 막히면 옆으로 비켜 가며 돌아옵니다. 실제 맵 90초 시험에서 막혀 멈춘 시간은 0.3초였지만, 맵의 모든 구역을 확인하지는 않았습니다.
- **돌진 범위 모양:** 바닥 표시는 직사각형이고 실제 판정은 몸이 닿는 순간(원)입니다. 직사각형이 끝부분 모서리만큼 조금 더 넓으므로, 표시 밖에서 맞는 경우는 없습니다.
- **효과음:** 폭발 · 포효 · 침 · 경고음은 합성했지만 귀로 확인하지 못했습니다.

- **5단계 밸런스:** 무기별 수치(특히 SMG · LMG 의 퍼짐, 샷건 거리 감소, 근접 넉백)는 사람이 직접 해 보지 않았습니다. 숙련도 요구량도 실제 플레이 길이에 맞춰 조정이 필요할 수 있습니다.
- **근접 무기 손:** 근접 무기는 왼손으로 휘두르고 총은 오른손에 든 채로 내립니다. 방망이 · 도끼도 한 손 동작입니다.
- **4단계 밸런스:** 강화가 붙으면서 플레이어가 강해지므로 3단계 웨이브 곡선을 다시 조정해야 합니다. 사람이 직접 한 판은 확인하지 못했습니다. 테스트 봇이 첫 카드만 고르는 조건으로는 7분(웨이브 8)까지 버텼습니다.
- **희귀도 효과 차이:** 지금은 강화마다 희귀도가 하나로 고정입니다. 등급별 수치 차이는 구조(`UpgradeChoice.rarity`)만 마련해 두었습니다.
- **난이도 체감:** 웨이브 곡선은 자동 사수(가장 가까운 좀비를 쏘는 테스트 봇)로만 7분까지 돌려 봤습니다. 사람이 하는 난이도 체감은 확인하지 못했습니다. 4단계 성장 시스템이 들어오면 다시 조정할 예정입니다.
- **2단계 실제 플레이:** 사람이 직접 하는 난이도와 조작감(좀비 속도 2.2 대 플레이어 6.2, 공격 간격)은 확인하지 못했습니다. 플레이어가 훨씬 빨라서 도망치기 쉽습니다. 난이도 조절은 3단계(웨이브)에서 합니다.
- **경로 탐색 한계:** 격자 1단위라 아주 좁은 틈(약 1 미만)은 막힌 것으로 봅니다. 좀비끼리는 서로를 경로 계산에 넣지 않으므로, 좁은 통로에서는 줄을 서거나 밀려서 비켜 갑니다.
- **흐름장 재계산:** 테스트 환경에서 평균 0.7ms, 처음 몇 번(JIT 준비 전)은 최대 약 8ms 입니다. 실제 PC 에서는 측정하지 못했습니다.
- **피격 판정 형태:** 좀비 판정은 원기둥(반경 0.45, 높이 0.2~1.75)입니다. 쓰러지는 중인 좀비는 판정이 없어 총알이 통과합니다.

- **실제 FPS 는 측정하지 못했습니다.** 테스트 환경에는 GPU 가 없습니다.
  - 프레임 확보를 위해 렌더 배율 상한 1.5, 가벼운 PCF 그림자, 가로등 점광원 3개로 줄였고, 동적 해상도를 넣었습니다. 평균 50FPS 미만이면 1초마다 렌더 배율을 0.25씩 낮추고(최소 0.75), 58FPS 이상이 5초 유지되면 다시 올립니다. F3 패널의 "렌더 배율"에서 현재 값을 볼 수 있습니다.
  - 측정한 값: 게임 로직(그리기 제외) 약 0.12~0.15ms/프레임, 드로우콜 약 93, 삼각형 약 5.5만.
  - 60FPS 를 보장하지는 않습니다. 실제 PC 에서 F3 패널로 확인해 주세요.
- **사람이 직접 하는 플레이 감각**(조작감, 반동 세기, 카메라 거리)과 **효과음**은 실제로 듣거나 손으로 확인하지 못했습니다.
- Firefox · Safari 는 테스트하지 않았습니다.
- **총알 높이:** 총알은 일정한 높이(1.32)로 수평 비행합니다. 낮은 엄폐물 너머로는 쏠 수 있지만, 높은 물체의 윗부분을 조준하면 그 아래 총구 높이 지점을 향합니다.
- **카메라 미리 보기:** `CAMERA_CONFIG.aimLookAhead` 를 0 보다 크게 하면 조준 방향을 더 보여 주지만, 마우스를 크게 움직인 직후 화면이 미끄러져 조준이 굼떠 보이므로 기본값은 0 입니다.
- **조준 회전:** 캐릭터는 마우스를 즉시 바라봅니다(`aimTurnSharpness: 0`). 값을 주면 부드럽게 돌지만, 그만큼 발사 방향이 커서보다 늦어집니다.
- **애니메이션 겹침:** 절차적 애니메이션이라 특정 각도에서 팔 · 총이 몸통과 살짝 겹칠 수 있습니다.
- **건물 반투명:** 건물 단위로 처리하므로 캐릭터를 조금만 가려도 건물 전체가 반투명해집니다.
